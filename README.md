# SmartAttendace

SmartAttendace is an attendance management system designed to make attendance recording, processing, and student study management easier.

## Features

- Attendance management
- Camera/OCR-based attendance processing
- Excel export
- PDF generation
- Student dashboard
- Course management
- Study assistance
- Authentication
- Email notifications
- Payment/subscription system
- Responsive frontend
